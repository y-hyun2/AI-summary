# 정책/데이터 스키마 버저닝 전략 초안

## 요구사항
- 스마트 폴더 정책, 템플릿, 감사 로그 등 다양한 스키마를 장기적으로 유지보수할 수 있어야 합니다.
- 이전 버전과의 호환성을 유지하면서도 새로운 필드와 동작을 도입할 수 있어야 합니다.

## 제안
1. **버전 필드 필수화**: 모든 스키마에 `schema_version` 필드를 추가하고 SemVer 규칙을 적용합니다.
2. **마이그레이션 유틸리티**: `scripts/migrate_schemas.py`에서 버전 별 변환 함수를 제공하고, 단위 테스트를 포함합니다.
3. **검증 단계 분리**: 로드 시 스키마 버전을 검사하고, 호환되지 않는 버전은 경고 + Fail Fast 전략 적용.
4. **변경 로그 문서화**: `docs/specs/schema_versioning.md`에 변경 이력을 기록해 개발자/운영자 간 공유.

## 호환성 정책
- **Major 업데이트**: 파괴적 변경, 명시적 마이그레이션 필요
- **Minor 업데이트**: 신규 필드 추가, 기본값 제공 시 자동 마이그레이션 가능
- **Patch 업데이트**: 버그 수정, 기본적으로 호환됨
